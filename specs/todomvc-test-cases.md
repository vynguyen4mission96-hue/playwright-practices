# Test Cases Specification: TodoMVC React Application

- **Application URL:** https://todomvc.com/examples/react/dist/
- **Test Scope:** Functional Testing
- **Specification Type:** Markdown Table

---

| index | TC name | objective | pre-condition | test data | steps | expected |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| TC-01 | Initial Page Load & Empty State | Verify the application displays the default clean state when no todos exist | Browser navigated to application URL | None | 1. Navigate to `https://todomvc.com/examples/react/dist/`<br>2. Observe the page elements | 1. Header with title "todos" is visible.<br>2. Input field with placeholder "What needs to be done?" is visible and focused.<br>3. Main section (todo list) and Footer are not displayed. |
| TC-02 | Add Single Valid Todo | Verify adding a new single todo item | Page is loaded with empty state | Todo text: `"Buy groceries"` | 1. Click input field "What needs to be done?"<br>2. Enter `"Buy groceries"`<br>3. Press `Enter` key | 1. Input field is cleared.<br>2. New item `"Buy groceries"` appears in the list.<br>3. Checkbox is unchecked.<br>4. Footer appears showing `"1 item left!"`. |
| TC-03 | Add Multiple Todos | Verify adding multiple distinct todos in sequence | Page is loaded with empty state | Item 1: `"Buy groceries"`<br>Item 2: `"Pay electricity bill"`<br>Item 3: `"Read book"` | 1. Type Item 1 and press Enter.<br>2. Type Item 2 and press Enter.<br>3. Type Item 3 and press Enter. | 1. All 3 items are displayed in order of creation.<br>2. Footer counter displays `"3 items left!"`.<br>3. "Toggle All" button becomes visible. |
| TC-04 | Prevent Empty Todo Creation | Verify empty todo cannot be added | Page is loaded | Empty string `""` | 1. Click input field.<br>2. Leave it empty.<br>3. Press `Enter` key. | 1. No new item is added to the list.<br>2. Input field remains empty and focused. |
| TC-05 | Prevent Whitespace-only Todo Creation | Verify todo consisting only of spaces is not created | Page is loaded | Whitespace string: `" "` | 1. Click input field.<br>2. Type 5 spaces `" "`<br>3. Press `Enter` key. | 1. No new item is added to the list.<br>2. Input field is either cleared or remains unchanged without adding empty item. |
| TC-06 | Trim Whitespace on Todo Creation | Verify leading and trailing spaces are trimmed when creating a todo | Page is loaded | Input: `" Clean the desk "` | 1. Click input field.<br>2. Enter `" Clean the desk "`<br>3. Press `Enter` key. | 1. Item is added with trimmed title: `"Clean the desk"`.<br>2. No leading or trailing spaces are saved. |
| TC-07 | Complete Single Todo Item | Verify marking an active todo as completed | Todo list has at least 1 active item (`"Buy groceries"`) | None | 1. Click the circular checkbox next to `"Buy groceries"` | 1. Checkbox is checked.<br>2. Item text has strikethrough styling (`completed` class).<br>3. Counter decrements (e.g. from `"1 item left!"` to `"0 items left!"`).<br>4. `"Clear completed"` button appears in the footer. |
| TC-08 | Revert Completed Todo to Active | Verify unchecking a completed todo sets it back to active | Todo list has 1 completed item (`"Buy groceries"`) | None | 1. Click the checked checkbox of `"Buy groceries"` | 1. Checkbox becomes unchecked.<br>2. Strikethrough style is removed.<br>3. Counter increments back to `"1 item left!"`.<br>4. `"Clear completed"` button disappears if no other completed items remain. |
| TC-09 | Verify Pluralization in Items Counter | Verify singular ("item") and plural ("items") in footer counter | 2 active todos created | None | 1. Observe counter with 2 items.<br>2. Complete 1 item and observe counter.<br>3. Complete remaining item and observe counter. | 1. With 2 active items: displays `"2 items left!"`.<br>2. With 1 active item: displays `"1 item left!"` (singular).<br>3. With 0 active items: displays `"0 items left!"`. |
| TC-10 | Toggle All Todos as Completed | Verify "Toggle All" checkbox completes all active items simultaneously | List contains 3 active items | None | 1. Click the "Toggle All" icon (`❯ Toggle All Input`) | 1. All 3 items are marked as completed.<br>2. All individual checkboxes are checked.<br>3. Counter displays `"0 items left!"`.<br>4. `"Clear completed"` button is visible. |
| TC-11 | Toggle All Todos to Active | Verify "Toggle All" unchecks all items when all are completed | List contains 3 completed items, Toggle All is checked | None | 1. Click the "Toggle All" icon (`❯ Toggle All Input`) | 1. All 3 items are marked as active.<br>2. All checkboxes become unchecked.<br>3. Counter updates to `"3 items left!"`.<br>4. `"Clear completed"` button disappears. |
| TC-12 | Auto-Update Toggle All State | Verify Toggle All state updates dynamically based on individual item status | List contains 2 items | None | 1. Complete item 1.<br>2. Complete item 2.<br>3. Uncheck item 1. | 1. When all items are checked individually, Toggle All checkbox automatically becomes checked.<br>2. When item 1 is unchecked, Toggle All checkbox automatically unchecks. |
| TC-13 | Edit Todo Text via Double-Click and Enter | Verify editing an existing todo text and saving via Enter | List contains `"Buy groceries"` | Edited text: `"Buy organic groceries"` | 1. Double-click the label `"Buy groceries"`.<br>2. Clear or append text to `"Buy organic groceries"`.<br>3. Press `Enter` key. | 1. Edit input field disappears.<br>2. Item label displays `"Buy organic groceries"`.<br>3. Todo retains its active/completed state. |
| TC-14 | Save Edited Todo via Blur (Click Outside) | Verify editing an existing todo and saving when clicking outside the input | List contains `"Read book"` | Edited text: `"Read 2 chapters"` | 1. Double-click label `"Read book"`.<br>2. Change text to `"Read 2 chapters"`.<br>3. Click anywhere outside the edit field (e.g. on background or footer). | 1. Edit mode exits.<br>2. Item text is successfully saved as `"Read 2 chapters"`. |
| TC-15 | Cancel Edit via Escape Key | Verify canceling an edit restores original text without changes | List contains `"Pay electricity bill"` | Attempted text: `"Pay water bill"` | 1. Double-click label `"Pay electricity bill"`.<br>2. Clear and type `"Pay water bill"`.<br>3. Press `Escape` key. | 1. Edit mode exits.<br>2. Item retains its original text `"Pay electricity bill"`.<br>3. Changes are discarded. |
| TC-16 | Delete Todo by Clearing Text in Edit Mode | Verify clearing all text in edit mode removes the item | List contains `"Task to delete"` | Text: `""` (empty) | 1. Double-click label `"Task to delete"`.<br>2. Select all text (`Ctrl+A`) and press `Backspace`.<br>3. Press `Enter` key. | 1. Item is completely removed from the list.<br>2. Items counter decrements accordingly. |
| TC-17 | Delete Todo via Destroy Button (x) | Verify deleting a todo by clicking its delete icon | List contains `"Buy groceries"` | None | 1. Hover mouse over the item `"Buy groceries"`.<br>2. Click the `"×"` (Delete todo) button on the right side. | 1. Item `"Buy groceries"` is removed from the list.<br>2. Items counter is updated. |
| TC-18 | Filter Active Todos | Verify filtering displays only active (uncompleted) items | List has 2 active items and 1 completed item | None | 1. Click `"Active"` filter link in footer.<br>2. | TC-19 | Filter Completed Todos | Verify filtering displays only completed items | List has 2 active items and 1 completed item | None | 1. Click `"Completed"` filter link in footer.<br>2. | TC-20 | Filter All Todos | Verify "All" filter displays all items regardless of completion | In `#/completed` or `#/active` view | None | 1. Click `"All"` filter link in footer.<br>2. Observe displayed items. | 1. URL changes to `#/`.<br>2. `"All"` link has `selected` styling.<br>3. All active and completed items are displayed. |
| TC-21 | Clear Completed Todos | Verify "Clear completed" button removes all completed items | List has 2 completed items and 1 active item | None | 1.
